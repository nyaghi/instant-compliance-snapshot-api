# 29.2EK: North Carolina In-Process application precedence

The public NC registry can label a numberless charity card `In-Process` while also displaying `Expired License` and historical expiration/extension dates. Version 29.2EJ retained this card, but classified its expired label as `Delinquent`. The user clarified that an In-Process record without an issued charity license number is a pending application. The master now classifies that exact source shape as `Pending` and still shows the registry's label and dates in the comment. An identified issued SL/EX license with `Expired License` remains `Delinquent`; a withdrawn unissued application remains `Closed / Withdrawn / Canceled`.

This change adds no organization exception, query, retry, time budget, or connector permission. The existing 0.6.127 connector continues to extract and bind the card; only the master interpretation and displayed release label change. A completed source record is still required, and unrelated or malformed cards cannot create a positive match.

The NC source and master regression suite passed 141 of 143 controls; the two failures are historical AST-baseline comparisons that also fail on the unchanged prior release. Focused NC classification and identity tests passed 4/4; NC public DOM passed 33/33; NC compound planner passed 13/13; NC partial-evidence controls passed 4/4; workflow controls passed 18/18.

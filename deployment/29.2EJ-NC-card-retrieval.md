# 29.2EJ: North Carolina numberless expired card

The October 11 Iron Light Labs trace reached one completed North Carolina result, then stopped in `ncRows` with `REGISTRY_NC_CARD_CHANGED`. The official card was categorized `In-Process`, showed `Expired License` and both expiration/extension dates, but displayed no SL/EX number. The prior card guard treated only plain In-Process and Withdrawn as numberless cards, so the master never received the result. This change is keyed to the registry's labeled category, status, dates, official profile URL, and card identity; no organization name, EIN, or expected outcome enters runtime rules.

The connector now retains this exact source shape. The master validates the official profile link and a parseable expiration date, uses the existing adverse-status precedence (`Expired License` → `Delinquent`), and explains that no issued license number is displayed. It adds no search, detail request, retry, or deadline. Plain pending/withdrawn, issued SL and EX, zero-result searches, malformed cards, and unrelated identities retain their prior handling.

The saved Fresh Test expectation for the reported record is `Pending`; the current source simultaneously displays `In-Process` and `Expired License`, with past dates. This is categorized as **needs manual review of sheet expectation/source interpretation**. The sheet has not been edited. Production promotion is withheld pending that review and post-deployment controls.

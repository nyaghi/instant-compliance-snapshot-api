Cleanup is hardcoded to the charity-search origin. No broad cookies/history/cache removal, parent-domain cookies, other sites, third-party verification data, or browser security settings. Persist the shared repair budget across worker restarts. On interruption, recover queued admissions where safe and return an explicit bounded interruption for uncertain in-flight searches. Never replay or reinterpret an unknown response. Repeated refresh clicks join one operation.

Nonprofit fundraising compliance

State charitable solicitation registration for nonprofits.

If your nonprofit asks the public for donations, sells tickets for a fundraising event, runs online campaigns, or accepts gifts through a Donate button, you may need charitable solicitation registration and a state filing plan in one or more states.

When charitable solicitation registration is usually triggered

Rules vary by state, but registration questions usually begin when a nonprofit asks for charitable contributions from residents, donors, businesses, sponsors, or event attendees. Online fundraising can matter because donation pages and campaign links may be accessible across state lines.

Multi-state registration planning
  • Public donation appeals, direct mail, email campaigns, text campaigns, or social media fundraising.
  • Website Donate buttons, giving platforms, peer-to-peer campaigns, or crowdfunding pages.
  • Fundraising events, sponsorship solicitations, raffles, auctions, or ticketed campaigns.
  • Professional fundraiser or consultant activity connected to public appeals.
  • Renewal deadlines after the organization is already registered in a state.

FAQ

What is state charitable solicitation registration?

State charitable solicitation registration is the filing process many states require before a nonprofit asks residents, donors, sponsors, or event attendees for charitable contributions.

Is charitable solicitation registration the same as nonprofit fundraising registration?

Often, yes. Many people use nonprofit fundraising registration to describe state charitable solicitation registration before asking the public for donations.

Does a Donate button trigger registration?

It can create a state fundraising question, especially when donations are accepted from residents of states with charitable registration rules. The answer depends on state rules and your activity. See our Donate button charitable registration guide.

Which states require charitable solicitation registration?

Many states require registration before a nonprofit asks residents for donations. Requirements vary, so most organizations start with the states where they actively fundraise or have a donor base. Browse the state-by-state guides for a quick read.

How can I check if we're compliant in one state?

Run a fast CharityClarity Aurora snapshot for one organization in one state. If you need a multi-state plan, contact Compliance Express.

What happens if a nonprofit is already delinquent?

Many states allow recovery through missed filings, corrected attachments, fees, and updated records. Some situations require a pause, reinstatement, or clean close-out strategy.

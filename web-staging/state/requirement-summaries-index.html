How to use this directory

Separate the registration question from the filing checklist

State charity registration requirements do not form one national rule. The IRS explains that many states regulate solicitation and may require registration before a charity asks residents for contributions, while exclusions and exemptions vary. Start by identifying the fundraising activity and jurisdiction; then use the relevant state guide to examine the registration, renewal, recovery, or close-out path. Confirm current forms and instructions with the state regulator before filing.

1. Registration

Use when the organization is entering a state, starting targeted fundraising, or discovering that a prior filing may never have been completed.

2. Renewal

Use for recurring reports, financial attachments, changing fees, extensions, officer signatures, and public-status confirmation.

3. Recovery

Use when the state record shows delinquent, expired, suspended, revoked, reporting incomplete, or another not-current signal.

4. Close-out

Use when solicitation has stopped and the organization needs to determine whether final reports, notices, or withdrawal steps remain.

Five facts to gather before comparing states

Fact Why it matters Where to look
Fundraising channels Mail, email, events, grants, online ads, donation pages, and peer-to-peer campaigns can create different factual questions. Campaign plans, platform settings, event calendar, grant pipeline.
Geographic activity A state review should follow where requests are directed and where meaningful fundraising activity occurs. Donor reports, mailing lists, ad targeting, programs, staff and offices.
Organization type State exemptions can depend on entity, religious, educational, membership, governmental, or other facts. Governing documents, IRS determination letter, bylaws, program description.
Financial profile Contribution or revenue amounts may affect exemptions, fees, financial statements, audits, and filing forms. Form 990, trial balance, contribution reports, audited or reviewed statements.
Existing state record A prior registration can create renewal or close-out obligations even when current fundraising plans changed. State registry, certificates, receipts, notices, and portal history.

State filings are separate from the IRS annual return

The IRS notes that a state can require additional forms, questions, financial statements, audit material, or deadlines even when it accepts a Form 990 copy as part of the report. Keep the federal return and every state filing as related but separate workstreams. A federal extension should not be treated as a state extension unless the state says so.

Frequently asked questions

Are charity registration requirements the same in every state?

No. Registration triggers, exemptions, forms, fees, attachments, renewal deadlines, and public status rules differ by jurisdiction.

Does filing Form 990 satisfy state charity registration requirements?

Not necessarily. A state may accept Form 990 as one attachment while still requiring a state form, fee, signatures, supplemental financial statements, or other information.

How should a nonprofit use these state guides?

Use the guides to identify the likely filing path and questions to resolve, then confirm current requirements with the applicable state charity regulator before filing.

STAGING PROTOTYPE · VERSION 0.1.0

Connect New York searches to Chrome

The connector opens New York’s registry in your browser. CharityClarity confirms the organization’s record and interprets the filing information.

Download staging connector
  1. Download the ZIP file and extract it to a folder you can keep on this computer.
  2. In Chrome, open chrome://extensions and turn on Developer mode. This is required for this unpublished staging prototype.
  3. Select Load unpacked and choose the extracted folder containing manifest.json.
  4. Return to CharityClarity staging and refresh the page. After unlocking staging, the connector should show as ready.

Keep Chrome open while New York checks run. A New York tab opens briefly for each search, then closes when the response is received.

This prototype works only with CharityClarity staging and New York’s registry. It does not send browser cookies, verification tokens, or your CharityClarity passcode to the connector. To remove it, use Chrome’s Extensions page.
